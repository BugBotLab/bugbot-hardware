# Mechanical

Chassis, mat and printed parts.

Today the CAD lives in BugBotLab's cloud drive (`Mech Design`), not yet in this repo. It moves here as STEP plus the printable STL/3MF files once the new three-board stack has been fitted to the chassis (the stack is 7.1 mm between boards with 5.6 mm sockets).

What belongs here when it lands:

- `chassis/` the printed frame that carries the three boards, the four motors and the battery
- `mat/` the silicone mat and any printed marker layout (AprilTags for absolute position)
- `print/` ready-to-print files with the print settings used
